# Integrationsnotiz - 08. Juni 2026

## Ziel

Der Laserpointer-Service soll auch ohne angeschlossenen Arduino testbar sein,
damit Controller und Interface die HTTP-Schnittstelle unabhängig von der
Hardware integrieren können.

## Umgesetztes Verhalten

- `POST /laser` versucht bei Bedarf automatisch, einen Arduino über USB zu
  finden.
- Wird keine Hardware gefunden, bleibt der Request erfolgreich und der Service
  meldet den Simulationsmodus.
- Das serielle Kommando wird im Log als simuliert erfasst.
- `GET /laser/health` zeigt, ob echte Hardware aktiv ist und welche Servo-Werte
  zuletzt berechnet wurden.

## Beispielantwort ohne Arduino

```json
{
  "success": true,
  "message": "Laser pointing to X:36deg Y:81deg (simulated)",
  "warning": "No Arduino found on USB ports. Operating in simulation mode.",
  "coordinates": {
    "x": 0.2,
    "y": 0.1
  },
  "servo": {
    "x": 36,
    "y": 81
  }
}
```

## Deaktivierung

Der Controller deaktiviert den Laser mit folgendem Payload:

```json
{
  "x": -1,
  "y": -1,
  "confidence": 1.0
}
```

Der Service setzt den Status auf `idle` und sendet beziehungsweise simuliert
das Kommando `X90Y90`.
